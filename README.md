# ✅ Modern Task Manager App

A full-stack task management application with modern UI/UX, dark mode, and real-time updates.

## 🚀 Features

- ✨ **Modern UI** - Clean design with smooth animations
- 🌙 **Dark Mode** - Automatic theme switching with persistence
- 📱 **Responsive** - Works perfectly on all devices
- 🔄 **Real-time Updates** - Instant feedback on all actions
- 🎯 **Task Management** - Create, read, update, delete tasks
- 🏷️ **Priority Levels** - LOW, MEDIUM, HIGH
- 💾 **Persistence** - Data stored in PostgreSQL database

## 🛠️ Tech Stack

- **Frontend**: React, TypeScript, Tailwind CSS, Framer Motion
- **Backend**: Node.js, Express, TypeScript, Prisma ORM
- **Database**: PostgreSQL
- **State Management**: React Query
- **Authentication**: JWT
- **Validation**: Zod
